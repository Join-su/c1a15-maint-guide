# 정비 길잡이 (C1-a15) 작업 폴더

캡스톤 과제 10 제안 C1-a15 "파트장이 승인할 수 있는 지시만 내는 야간 정비 Agent"를 구현하기 위한 폴더입니다.
지금은 과제 10 이 요구하는 입력 데이터 세 가지 중 **새로 만들어야 하는 두 가지(가상 정비 매뉴얼, 정비 이력 300건)**만 들어 있습니다.
나머지 하나인 이상 이벤트(센서 값)는 원본 CSV 와 `data/alarm_rules.json` 의 규칙으로 만듭니다.

- 기준 문서: `eval-ideal/session-run-v1.2/C1/submissions/C1-a15.md`, `eval-ideal/docs/C1-a15-user-guide/정비길잡이-사용가이드.pdf`
- 원본 데이터: `manifact_10/data/raw/ai4i2020.csv` (복사하지 않고 경로로 읽음, 해시는 `data/manifest.json`)
- 참고한 자료: `agent-10/task10_maintenance/data/` 의 매뉴얼(MC01-MM)·정비 이력 형식. 그 폴더는 건드리지 않았습니다.

평가 카드(10~12월 알람 30건의 숨은 원인과 점검 메모)는 C1-a15 원칙대로 **이 생성 규칙을 보지 않은 팀원**이 따로 씁니다. 여기에는 만들지 않았습니다.

## 다시 만들기

```bash
python3 scripts/build_data.py            # 기본 CSV 경로: ../manifact_10/data/raw/ai4i2020.csv
python3 scripts/build_data.py --csv PATH
```

고정 seed 라 다시 돌려도 같은 파일이 나옵니다. 실행 때 아래를 검사하고, 어기면 멈춥니다.

- 이력의 모든 매뉴얼 참조가 실제 절이다.
- 모든 이력이 1~9월이고, 잠금 확인으로 시작한다.
- C·D등급 점검·조치는 파트장 호출 기록 뒤에만 나온다.
- 매뉴얼에 UCI 고장 생성 조건 수치(8.6 K, 1,380 rpm, 3,500/9,000 W, 11,000~13,000, 240분)가 없다.
- 모든 원인에 확정 점검이 있다.

## 설계 요약

- **라벨 분리**: CSV 의 고장 라벨 6열(Machine failure, TWF, HDF, PWF, OSF, RNF)은 읽자마자 버립니다. 원인은 비율표로만 뽑습니다.
- **행 배치**: 행 순서가 시간 순서(공기 온도가 연속, 공구 마모가 증가 후 리셋)라 순서를 유지합니다. 온도 차가 낮은 더운 구간이 9월 말~10월 초에 걸치도록 시작점만 옮겼습니다(2,989행). 설비는 위치 % 20 + 1(M-01~M-20), 한 행은 약 52.6분 간격입니다. 이 배치에서 온도 차 저하 알람은 9월 158건, 10월 213건입니다.
- **알람**: 1~9월 분포로 경계를 정합니다. 출력 이탈(하위 4,210 W / 상위 8,366 W), 온도 차 저하(8.3 K 미만), 토크 과부하(59.7 Nm 초과), 공구 마모 경고(214분 초과). 동시에 이탈하면 출력 → 온도 → 토크 → 공구 순으로 주 증상군을 정합니다.
- **매뉴얼**: 증상군 4개 × 6절 = 24절(개요, 사전 확인, 점검 4개). 점검 16개, 원인 14개. 각 점검은 원인 하나에 연결되고, 두 점검(3.5 인버터 이력, 5.5 진동)은 의심만 주는 선별 점검이라 확정 점검(3.6, 5.6)이 뒤따릅니다.
- **이력 300건**: 1~9월 알람 750건 중 온도 차 저하·토크 과부하는 모두(158 + 47), 출력 이탈·공구 마모는 비율대로 뽑았습니다(65 + 30). 정비자 연차에 따라 점검 순서가 다릅니다(1~3년차는 목차 순, 5년차 이상은 등급·소요 분 순). 야간·주말에는 C등급 작업마다 파트장을 호출하고 "승인 후 진행"이나 "주간 처리"로 갈립니다.

## 사용 가이드와 다른 점

가이드의 예시 값과 이 데이터의 값은 다릅니다. 시나리오 흐름은 같습니다.

- 온도 차 하위 경계: 가이드 7.9 K → 데이터 8.3 K. 배치를 옮기면서 1~9월 분포가 바뀌었습니다.
- 냉각 설정값 변경: 가이드 5.2절 → 매뉴얼 4.6.2절. 재가동 6.1, 전기 계통 7.1, 필터 4.3/4.3.2, 팬 분해 4.4, 잠금 1.2 는 같습니다.
- 냉각수 보충: 가이드 4.5절 → 매뉴얼 4.5.2절(4.5 는 수위 확인).
- 이력 번호: 300건이라 가이드의 H-0347·H-0458 같은 번호는 없습니다.
