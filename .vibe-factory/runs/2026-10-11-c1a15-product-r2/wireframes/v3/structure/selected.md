# 승인 구조 청사진 · wireframe_structure v3

선택 결과: 후보 `guide-a`(사용 가이드 화면 그대로 + 새 화면 T12 · T13 · T14 · T15, 새 상태 T06 / b_precheck · L05 / raise_warning)의 58개 화면 전체. 사용자 승인 2026-10-12(v3). 이 문서는 `wireframes/v3/structure/selected/`의 실제 화면에서 뽑은 구조 · 내용 · 행동 기준이다. 화면을 다시 그리는 지시가 아니다.

## Rendering rule

- 구조 기준선은 `selected-visual-baseline.json`의 화면(path · hash 고정)이다. 영역 배치, 정보 단위, 탐색, 작업 순서, 필수 정보, 상태 의미, 조작 위치를 지킨다.
- 서체 · 색 · 표면 · 모서리 · 그림자는 G2B에서 다시 정한다. 단, 등급 배지(A~D), 상태 점 · 칩, 잠긴 버튼처럼 의미를 전하는 표시는 의미를 유지한다.
- 정비자 앱은 1080 × 740 태블릿 화면, 파트장 앱은 1280 × 620 PC 화면을 기준 크기로 쓴다.
- 영역 하나에는 구조 방식 하나만 쓴다. 표와 카드를 함께 허용하지 않는다.
- 화면 값은 sample(`wireframes/v3/samples/review-sample.json`)이다. 실제 값은 구현에서 계산한다.
