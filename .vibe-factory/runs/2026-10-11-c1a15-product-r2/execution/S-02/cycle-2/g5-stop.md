# S-02 2차 cycle G5 중단 기록 (2026-10-13)

P-18(진단 미리보기 보강)을 구현 · 시험한 뒤(통합 시험 21 passed), P-08(정비자 앱 화면)을 시작하려고 Prototype v17의 정비자 화면 template 24개(T01 ~ T07 · T12 ~ T14)를 지금 API 응답과 대조했다. 화면이 보여야 하는데 API가 주지 않는 값이 있었다. 승인 권한 경계('화면은 API가 준 값만 보인다')라 앱이 만들 수 없다.

| 화면 | 빠진 값 |

원인: S-02 1차 cycle의 P-06(API)을 화면 없이 만들어 화면 값 대조를 끝까지 못 했다. 이 값을 더하면 공개 API 응답이 바뀐다(L1). 실행 카드의 허용 서버 변경은 '미리보기 · 결과 입력 검증'뿐이다.

사용자 결정(선택지 원문): "L1 수정으로 P-19 추가 (권장)" — 변경 기록 A-03 → plan v7에 새 item P-19('정비자 화면 값 API 보강', S-02 2차 cycle), AI 해석 문장은 R8 근거 검사, 독립 검토 한 번 → 승인 뒤 구현. P-18과 설치한 패키지는 그대로. 선택하지 않은 선택지: '이 cycle에서 L0로 채움' · '여기서 멈춤'.

값 가운데 승인 묶음 · 구현 명세에 정의가 없는 네 가지는 사용자에게 물어 결정 014(`sources/intent/014.md`)로 정했다. 데이터에 이미 있는 값: 설비 종류(이력 equipment_type · 매뉴얼 제목 '회전 가공 설비'), 계통(매뉴얼 장 제목 괄호, 예 '4. 온도 차 저하 (냉각 계통)'), 승인자(이력 approval.by), 유사 %(R3 '유사도 % = score × 100'), 잠금 절차(R1 '세션의 첫 단계는 1.2절 잠금 확인').
