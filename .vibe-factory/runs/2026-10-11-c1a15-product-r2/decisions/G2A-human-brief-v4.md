# Gate Brief: G2A / wireframe_structure v4

## 쉬운 설명

v3(승인) 화면 58개에 새 상태 11개를 더하고 두 곳을 바꿨다. 전체 69개 상태다(사용자 결정 010 · 011).
- **상단 '홈'**: 정비자 앱 모든 화면 상단 바(종 왼쪽)에 있다. 홈 화면에서는 현재 위치로 표시된다. 누르면 확인 없이 홈으로 가고, 진행 중 세션은 홈의 '이어서 하기'로 돌아온다.
- **T15 지난 화면**(바뀜): 진행 표시의 완료 단계를 누르면 요약 창 대신 그 단계의 원래 화면이 그때 값으로 열린다.
  - 위 띠: '지난 화면 · 단계 · 제출 시각', 같은 단계 기록을 넘기는 '이전 · 다음'(예: 점검 단계 1/3 잠금 · 2/3 사전 확인 · 3/3 4.3), '현재 단계로'. 진행 표시에는 지금 보는 단계가 테두리로 표시된다.
  - 조작은 잠긴 보기 상태다. 정비자가 입력한 값(점검 결과 · 메모 · 사전 확인 측정값)에는 '이 기록 정정', 잠금 · 조치 · 재가동 기록에는 '메모 덧붙이기'만 있다.
- **정정 흐름**(새 상태): 정정 창(원래 값 · 정정할 결과 · 메모 · 사유 필수, 사유 없으면 '정정 저장' 잠김) → 열린 지시가 바뀌면 확인 창(지워질 입력 안내, 취소 / 정정 저장) → 정정 뒤(최신 값 · '정정 1회' · 이전 값 · 사유) → 다시 판정 뒤 조치 화면의 점검 경로에 '정정으로 무효'(T08 / corrected_path).
- **예외**: 조치 뒤 정정은 다시 판정 대신 호출 요약(T10 / summary_corrected), 보낸 호출에 붙은 정정은 파트장 호출 상세의 '보낸 뒤 정비자 정정' 상자(L04 / call_corrected).
- **정정할 수 없을 때**: 보고서를 확정한 세션의 지난 화면에는 정정 버튼 대신 '확정한 세션이라 정정할 수 없습니다 · 반려되면 다시'(T15 / closed). 메모 덧붙이기 창(T15 / note).
- **파트장 감사 기록**: 정정 · 메모 덧붙이기 행(L06 / correction).

새 참고 자료는 없다. 지난 화면은 같은 화면 구조를 기록 보기로 다시 여는 원리(RP-02 · RP-07), 홈은 같은 자리의 전역 이동(RP-01)을 쓴다.

후보 수 예외 사유(candidate_count_exception_reason): wireframe_structure v4: v3(승인)에 G3 Human Gate(v13 승인 뒤) 사용자 결정 010 · 011에 따른 바뀜을 더했다. 정비자 앱 모든 화면 상단 바에 '홈'(종 왼쪽)을 두었다. T15는 지난 단계 보기 창(요약)을 지난 화면(그 단계의 원래 화면을 그때 값으로 다시 그림 + 위 띠의 제출 시각 · 이전 · 다음 · 현재 단계로)으로 바꾸고, 정정 창 · 정정 확인 · 정정 뒤 · 메모 덧붙이기 · 확정한 세션 상태를 더했다(11 상태). T08 / corrected_path(다시 판정 뒤 '정정으로 무효'), T10 / summary_corrected(조치 뒤 정정 호출), L04 / call_corrected(보낸 호출에 붙은 정정), L06 / correction(정정 기록)을 더했다. 상단 홈 버튼과 지난 화면 · 정정은 가이드에 없어 같은 시각 언어로 만들었다(D17 예외). 후보는 guide-a 하나다. 사용자가 G0에서 'G2A·G2B는 사용 가이드 화면을 유일한 안으로 한다'(D17)를 승인했다. 그래서 다른 화면 토폴로지·정보 단위·상호작용 방식의 후보를 만들면 승인 결정을 뒤집게 된다. 제외한 구조는 세 가지다. (1) 목록-상세 분할 화면 하나에서 순위와 점검을 함께 처리하는 안: 태블릿 한 화면에 점검 하나만 보이게 한 가이드 원칙과 맞지 않는다. (2) 보드형 점검 대기열 안: 지시된 점검 하나를 따르는 흐름(AC-35)을 깨고 건너뛰기를 유도한다. 진행 표시를 탭처럼 눌러 현재 단계를 바꾸는 안도 같은 이유로 제외했다(지난 화면은 보기 상태로만 열리고 '현재 단계로'로 돌아온다). 지난 화면에서 결과를 바로 고쳐 쓰는 안(정정 창 없이 제자리 편집)도 사유 · 원래 값 기록을 건너뛰게 해 제외했다. (3) 파트장 앱을 받은편지함형 한 목록으로 합치는 안: 가이드 15~17쪽의 메뉴 4개 구조를 바꾼다.
