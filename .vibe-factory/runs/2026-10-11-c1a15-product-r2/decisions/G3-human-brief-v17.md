# Gate Brief: G3 / prototype v17

## 쉬운 설명

v16(승인) 위에 화면 상태 하나만 더한 판입니다. 구현 S-02에서 판정 엔진을 만든 뒤 여쭌 OOS-01 결정(`sources/intent/013.md`: "다음 점검 카드에 호출 안내")을 반영했습니다. 첫 판정이 바로 파트장 호출일 때의 진단 화면이 승인 화면에 없었기 때문입니다.

| 경우 | 이제 이렇게 보인다 |
| --- | --- |
| 첫 판정이 바로 파트장 호출(1순위 원인을 확인할 점검이 C · D뿐이고 50% 이상, 또는 혼자 할 A · B 점검이 없음) | 진단 화면(T04) 구조 그대로: 순위 · 비슷한 과거 기록 · 강조 카드 하나 · 주 버튼. '다음 점검' 카드에 **파트장 호출 필요** · C 배지 · 매뉴얼 4.4절 · 확인 점검(냉각 팬 분해 점검 · 약 10분) · '호출이 필요한 이유'. 주 버튼은 그대로 '점검 시작'(호출 경고색 토큰) → 잠금 → 사전 확인 → 호출 요약(T10) |
| 이전 판(v16) | 진단 화면을 열지 않고 '이 진단 화면은 승인 화면에 없습니다' 안내만 |

시험 방법: 위 조작 막대의 **첫 판정 호출 세션: 켬** → 정비자 로그인 → '점검 시작' → '진단 보기'. (유사 기록 상위 10건 중 냉각 팬 열화 6건 → 61%.) 승인 sample 세션에서는 파트장 앱에서 4.3 · 4.5 · 4.6을 모두 C · D로 바꾸면 같은 화면이 나옵니다.

S-02에서 확인한 사실: 초기 등급표에서는 시연 각본 10건 모두 첫 판정이 점검 지시라, 이 화면은 등급을 바꿨을 때나 검색 결과가 CL-2 50% 이상일 때만 나옵니다.
